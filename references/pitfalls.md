# 可靠性与常见失败

- YouTube 字幕列表可能受工具版本、客户端响应、限流影响。网络失败/解析失败是 unknown，不能转成 absent。
- 自动字幕下载需精确选择原语言轨，批量翻译轨会扩大请求量并可能触发限流。
- 非交互读取浏览器 cookies 可能触发系统钥匙串提示；本技能不自动执行该操作。
- 模型输出可能整句复读、段内复读、退化成短数字段。检查时间轴及原音频，必要时缩小范围重转。
- “覆盖率”只能做时间轴检查：字幕到达音频末端不意味着中间每句话都被识别。短视频最后一段很长时应看 cue 结束时刻，不是开始时刻。
- 中文内容密度、数字游程等阈值是诊断启发式；静音、音乐、数字教学或非中文材料会误报。
- 术语表不能跨频道机械套用。`指引` 在一些语境是真词，不能直接替换为 `止盈`。
- `APL → AAPL` 不是幂等替换；使用上下文限定正则，应用前先检查整张词表的二次效果。
- 已生成 Markdown 的人工编辑应保留；cleaner 默认不覆盖，明确备份后才能选择覆盖。
- 日期不能唯一标识同日多视频。文件名保留视频 ID，总纲使用 ID 引用。
- 不展示来源不明的个人历史量化结果作为公开基准；本预发布只提供原创合成示例。
